Design notes

The live page can reuse the current roll/pitch horizon, relative-yaw estimate and motor-command readback. Color each status using its FC report. Green means healthy, amber means waiting, red means a detected fault, and gray means unavailable. Keep secondary controls for key mapping and bench tuning in their existing configuration workflows.
